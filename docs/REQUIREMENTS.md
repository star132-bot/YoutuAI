# 灰糯（Huinuo / Mochi）· YoutuAI 可爱助手需求文档 v0.2

> 一个可接入大模型（AI）的 Live2D 网页小助手：能聊天、有丰富动作反馈、会一步步教用户怎么操作。
> 可嵌入任意网页，也可用作 YouTube 直播 / 视频的虚拟形象。

---

## 1. 产品定位

| 项目 | 说明 |
|---|---|
| 形态 | 网页右下角的 Live2D 看板娘（可拖动、可最小化）+ 对话气泡 / 聊天面板 |
| 核心价值 | ① 陪聊 ② 操作引导（新手教程、功能讲解）③ 情绪化动作反馈，让交互更有温度 |
| 使用场景 | **A. 网站小助手 与 B. YouTube 直播，同等优先（已确定）**<br>A. 网站 / Web 应用的新手助手<br>B. YouTube 直播间虚拟主播（OBS 浏览器源）读弹幕并互动 |
| 目标用户 | 第一次使用某网站、不知道从哪下手的用户；直播观众 |

## 2. 角色设定

### 2.1 方向（已确定）
- **蓝色可爱小老鼠风格的二次元女孩**：鼠耳、细长鼠尾、蓝色系配色
- 多装饰：发饰、袜子、手持道具等

### 2.1.1 名字与性格（已确定）
- **名字**：灰糯（英文 Mochi，拼音 Huinuo）—— 灰色 + 软糯，圆滚滚的小老鼠
- **性格**：淘气 + 靠谱（反差萌）
  - 淘气：爱开小玩笑，偶尔装作把按钮藏起来；用户久不操作会戳屏幕；被戳多了会鼓脸假装生气
  - 靠谱：一到教操作就认真，分步骤讲清楚；用户做对了真心夸奖；不知道就老实说，不乱编
  - 小习惯：开心时尾巴铃铛叮叮响，紧张时耳朵会抖

## 3. 动作与表情系统（重点）

### 3.1 动作清单（Motions）

按分组组织，每组 1~3 个变体随机播放，避免重复感。

| 分组 | 动作 | 触发时机 |
|---|---|---|
| **Idle 待机** | 呼吸、眨眼、左右轻晃、整理头发、看向鼠标、打哈欠（长时间无操作） | 默认循环 |
| **Greet 问候** | 挥手、蹦一下 + 比耶、鞠躬 | 首次打开页面 / 重新回来 |
| **Talk 说话** | 口型同步 + 小幅手势（摊手、点头） | AI 回复播放时 |
| **Think 思考** | 手托下巴、歪头、呆毛变问号、眼睛看上方 | 等待 AI 响应时 |
| **Happy 开心** | 双手握拳「耶！」、转圈、脸红捂脸（被夸） | 用户完成任务 / 夸奖 |
| **Sad 难过** | 低头、手指戳手指、呆毛耷拉 | 用户说再见 / 报错 |
| **Angry 小生气** | 鼓腮帮、叉腰、跺脚（可爱向） | 被戳太多次 / 被骂 |
| **Surprise 惊讶** | 后仰 + 瞪眼、头顶「!」 | 出现错误 / 新消息 |
| **Point 指引** | 魔法棒指向**左 / 右 / 上 / 下**四个方向 | 教程：告诉用户「点这里」 |
| **Explain 讲解** | 拿出小黑板 / 翻书 | 讲解较长的说明 |
| **Nod / Shake** | 点头、摇头 | 回答「是 / 不是」 |
| **Sleep 睡觉** | 打盹、冒 Zzz 泡泡 | 5 分钟无操作 |
| **Poke 被戳** | 点头部：摸头开心；点身体：害羞躲闪；连点：生气 | 用户点击角色 |
| **Drag 拖拽** | 被拎起来时手脚乱晃 | 拖动窗口 |
| **Bye 告别** | 挥手 + 缩小进角落 | 最小化 |

**首版目标：≥ 15 组、≥ 30 个动作片段。**

### 3.2 表情清单（Expressions）
普通、微笑、大笑、害羞（脸红）、惊讶、难过、哭哭、生气（鼓腮）、疑惑、得意、困倦、星星眼。共 12 个，可与任意动作叠加。

### 3.3 Live2D 模型技术需求
- 工具：Live2D Cubism Editor 4/5，导出 `.model3.json` + `.moc3` + 纹理 + `.motion3.json` + `.exp3.json`
- 必需参数：头部 XYZ 角度、身体 XYZ、眼球 XY、左右眼开合、眉毛、嘴型开合 + 形状（用于口型同步）、脸红、呼吸、头发物理（双马尾、呆毛、裙摆）、手臂切换（普通 / 叉腰 / 举魔法棒）
- 物理演算：双马尾、呆毛、领结、裙摆
- 纹理：2048×2048，1~2 张，控制在 2MB 以内以保证网页加载速度
- **开发期占位**：先用 Live2D 官方免费示例模型（如 Hiyori / Haru）跑通全部功能，等原创模型完成后替换

## 4. AI 对话能力

### 4.1 多 AI 接入 + 自动切换（已确定）
- 统一的 `LLMProvider` 接口，可同时配置多个 AI（OpenAI 兼容接口、Claude、DeepSeek、通义千问等）
- **手动切换**：设置里可选当前使用的 AI
- **故障转移**：当前 AI 超时 / 报错 / 限流时，自动按优先级切换到下一个，并记录健康状态，恢复后可切回
- **安全**：API Key 只存在后端代理（环境变量），前端不可见；后端做限流

### 4.1.1 jev 判断层（决策模型）
jev 是位于聊天 AI 之前的「判断」模型：
- **输入**：网页端用户操作数据（点击、停留、报错、所在页面）+ YouTube 数据（弹幕、Super Chat、观众数等）+ 用户消息
- **知识**：给它站点功能说明、FAQ、教程脚本作为资料
- **输出**：判断该如何处理，例如：
  - 直接触发某个教程引导
  - 交给哪个聊天 AI 回复
  - 播放哪个动作 / 表情
  - 忽略（如重复弹幕、刷屏）
- 形式待定：可以是带知识库的 LLM 分类器，也可以是规则 + 小模型组合

### 4.2 AI 驱动动作：结构化输出
让 AI 在回复中同时给出情绪和动作，前端据此播放。约定输出格式：

```json
{
  "text": "这里这里！点右上角的「上传」按钮就可以啦~",
  "emotion": "happy",
  "motion": "point_right",
  "highlight": "#upload-btn"
}
```

- `emotion` / `motion` 只能取自白名单，非法值回退到 `talk`
- 流式输出时先播放 `think`，拿到首句后切换到对应动作
- 兜底：若模型不支持 JSON，则用关键词 / 情感分析本地推断动作

### 4.3 人设与记忆
- System Prompt 固化角色性格、说话风格、字数限制
- 短期记忆：最近 N 轮对话
- 可选长期记忆：记住用户昵称、已完成的教程（localStorage）

### 4.4 语音（第二阶段）
- TTS：可爱女声（如 Edge TTS、GPT-SoVITS 自训练音色），并根据音量驱动嘴型
- ASR：用户可按住说话

## 5. 操作引导（教程）功能

这是区别于普通看板娘的核心功能。

1. **引导脚本**：用 JSON / YAML 描述步骤，站长无需写代码即可配置
   ```yaml
   - target: "#upload-btn"
     say: "第一步，点这个上传按钮~"
     motion: point_right
     wait_for: click
   - target: "#title-input"
     say: "给你的视频起个好听的名字吧！"
     motion: explain
     wait_for: input
   ```
2. **高亮 + 指向**：遮罩高亮目标元素，角色自动移动到元素旁边，并用魔法棒指过去（根据相对位置选择 point_left/right/up/down）
3. **AI 自由问答 → 自动引导**：用户问「怎么改头像？」时，AI 从站点的功能清单（知识库）中检索，返回步骤并调用高亮
4. **完成反馈**：每一步完成播放开心动作；全部完成撒花 🎉
5. **可随时跳过 / 重播**

## 6. YouTube 直播模式
- 以 OBS「浏览器源」方式运行，透明背景
- 通过 YouTube Live Chat API 读取弹幕，AI 挑选回复
- Super Chat → 特殊感谢动作
- 敏感词过滤、回复频率限制

## 7. 交互与界面
- 角色可拖动、可缩放、可最小化为迷你头像
- 视线跟随鼠标
- 对话气泡（短回复）+ 可展开的聊天面板（历史记录）
- 快捷按钮：「我是新手」「这个页面怎么用？」「随便聊聊」
- 设置：音量、是否自动说话、角色大小、勿扰模式
- 移动端适配：缩小角色、聊天面板改为底部抽屉
- 无障碍：所有对话文字可被屏幕阅读器读取，支持「减少动态效果」

## 8. 技术方案（建议）

| 层 | 选型 |
|---|---|
| 渲染 | PixiJS + `pixi-live2d-display`（Cubism 4 Core） |
| 前端 | TypeScript + Vite，打包成**一行 `<script>` 即可嵌入**的 Web Component `<youtu-assistant>` |
| 后端代理 | Node (Hono / Express) 或 Cloudflare Workers，负责 AI 转发、Key 保管、限流 |
| 配置 | `assistant.config.json`：角色、AI 提供商、教程脚本 |

嵌入示例：
```html
<script src="https://cdn.example.com/youtu-assistant.js"></script>
<youtu-assistant api="/api/chat" model="/models/youtu/youtu.model3.json"></youtu-assistant>
```

### 非功能需求
- 首屏加载（含模型）< 3 秒，动画稳定 60fps，页面不可见时暂停渲染
- 不影响宿主页面样式（Shadow DOM 隔离）
- 注意 **Live2D Cubism SDK 授权条款**：小规模 / 个人免费，商用达到一定营收需签约
